# AI Opportunity Lab — Blair Page

A public-facing AI product strategy portfolio demonstration. The equipment rental scenario and scoring inputs are fictional and intentionally distinct from private coursework. No original assignment files are included.

## Publish with GitHub Pages
1. Create a repository named `ai-opportunity-lab`.
2. Extract the ZIP and upload its contents to the repository root (including `index.html` and `.nojekyll`).
3. In Settings → Pages, select Deploy from a branch, `main`, `/ (root)`, and Save.
4. Once published, link `https://blairyfairy.github.io/ai-opportunity-lab/` from your portfolio (assuming that account and repository name).

No dependencies, build tools, API keys, or server required. The scoring model runs locally in the browser. Public references support methodology only. No actual customer research or performance is claimed. Browser rendering and live external links have not been tested.

## Extended portfolio edition
Includes interactive weighting presets, CSV export, editable commercial model, SVG reference architecture and a 90-day validation roadmap. All scenario inputs are planning assumptions. No backend or external dependencies. Open index.html locally or deploy the repository root using GitHub Pages.
